01 — 한국항공우주학회 2025 추계학술대회
조종사 오류 방지를 위한
실시간 졸음 감지 및 단계별 경고 시스템
YOLOv8n PERCLOS Python OpenCV Arduino Roboflow MSFS
프로젝트 개요

조종사의 졸음 및 주의력 저하로 인한 항공 사고 위험을 줄이기 위해, YOLOv8n 기반 실시간 얼굴 상태 인식과 PERCLOS 지표를 결합한 4단계 경고 시스템입니다. Microsoft Flight Simulator(MSFS) 환경에서 주야간 조종사 얼굴 데이터를 직접 수집하고 Roboflow로 라벨링해 1,800장 학습셋을 구성했습니다.

데이터셋 수집 — MSFS + Roboflow

Microsoft Flight Simulator에서 주·야간 시뮬레이션 중 조종사 얼굴 영상 직접 캡처. Roboflow로 open_eye / closed_eye / head_down 3-class 라벨링. 총 1,800장 구성.

하드웨어 구성 — Arduino 경고 장치

PERCLOS 단계 신호를 시리얼 통신으로 Arduino에 전달, 단계별 버저 패턴 및 LED(초록·노랑·빨강)를 제어하는 경고 장치 제작.

주요 구현
  • MSFS 가상 환경에서 조종사 얼굴 주야간 데이터 1,800장 수집 및 Roboflow 라벨링
  • YOLOv8n 학습 (50 epoch): open_eye / closed_eye / head_down 3-class 실시간 분류
  • PERCLOS 지표 계산 → 4단계(정상 / 경고 / 위험 / head_down) 졸음 수준 정량화
  • Arduino 연동: 단계별 버저 패턴 + LED(초록·노랑·빨강) 실시간 제어
  • 프레임별 눈 상태 + PERCLOS 값 CSV 로깅 및 시계열 시각화

02 — 2025 C-PBL · 청주대학교 항공학부 무인항공기학
청주시 불법 주차 단속 드론
Raspberry Pi DJI Mini 5 Pro YOLOv8 OCR Python OpenCV Roboflow PID 제어
프로젝트 개요

청주시 불법 주정차 단속 건수가 2020년 203,146건에서 2024년 279,662건으로 지속 증가하는 가운데, 사각지대 문제를 해결하기 위한 2025 C-PBL 프로젝트입니다. Raspberry Pi 기반 자체 제작 드론에 YOLOv8 차량 탐지 + OCR 번호판 인식을 탑재, 이동형 단속 시스템을 구현했습니다. 팀장으로서 임베디드 시스템 구축 전반 담당.

문제 배경 — 청주시 불법주정차 단속 현황

2020~2024년 청주시 불법주정차 단속건수 꾸준히 증가. 고정형 CCTV 사각지대, 단속차량 협소 골목 진입 불가.

기존 단속 방식 vs 드론 단속
구분고정형 CCTV단속 차량드론 단속
단속 범위특정 지점 반경차량 진입 가능 도로사각지대 전역
기동성없음보통매우 높음
경제성설치·유지비 비쌈인건비 발생저비용 고효율
OCR 번호판 인식 파이프라인

Input Image → 번호판 영역 인식(YOLOv8) → +5~10% 확장 → OCR 문자 인식 4단계 파이프라인.

주요 구현
  • DJI Mini 5 Pro로 실제 도로 주정차 차량 항공 영상 데이터 직접 수집
  • Roboflow로 차량 및 번호판 영역 맞춤형 학습 데이터셋 구축
  • YOLOv8 차량 탐지 → 번호판 영역 추출 (인식 범위 5~10% 확장)
  • OCR 기반 번호판 문자 인식 → GCS 화면 실시간 대조 확인
  • Raspberry Pi 4에 딥러닝 모델 이식, 실시간 탐지 구현
  • PID 튜닝으로 기체 진동 문제 해결, 비행 안정성 확보
비행 테스트 — PID 튜닝

Rate Roll/Pitch P=0.135, I=0.090, D=0.0036 최적값 도출로 안정적인 호버링 확보.

서비스 개요

운행 중인 모든 버스의 실시간 위치와 혼잡도를 지도 위에 시각화하고, Random Forest 머신러닝 기반으로 정류장별 도착 시간을 예측하는 웹 서비스입니다. 현재 서울 여의도(162·261·461번)를 테스트 범위로 실제 배포 중이며, 동일 구조로 전국 확장을 목표로 합니다.

핵심 기능
  • 실시간 버스 위치 — 5초마다 공공 API를 호출해 지도 위 버스 아이콘 실시간 이동
  • 혼잡도 색상 아이콘 — 버스 아이콘 색상으로 혼잡도 즉시 시각화
  • 노선 구간별 혼잡도 — 경로선 자체를 구간별 정체 색상으로 구분
  • 신호등 카운트다운 — 여의도 교차로 19개의 신호 잔여시간 실시간 표시
  • AI 도착 시간 예측 — 정류장별 예측 도착 시간 자동 표시
  • 자동 데이터 수집 — 분당 1회 자동 수집 → Supabase 누적 저장

04 — 전세사기 예방 웹 서비스 · Vercel 배포
전세 안전 확인
이 집, 계약해도 될까요?
Next.js 16 TypeScript Tailwind CSS shadcn/ui Python 공공데이터 API CODEF
프로젝트 개요

전세 계약 전 임차인이 혼자서 핵심 위험 지표를 빠르게 확인할 수 있는 웹 서비스입니다. 주소와 보증금만 입력하면 정부 공공 API를 자동으로 조회해 전세가율(깡통지수), 건축물대장 이상 여부, 등기부 근저당·압류 정보를 한눈에 표시하고 SAFE / CAUTION / DANGER / UNKNOWN 4단계로 위험도를 즉시 판정합니다.

서비스 3단계 여정
  • 1단계 — 혼자 미리 확인: 주소 정규화 → 실거래가 조회 → 전세가율 계산 → 건축물대장 확인 → 등기부 확인 → SAFE / CAUTION / DANGER / UNKNOWN 판정
  • 2단계 — 중개인 만날 때: 중개사 등록 유효 여부 조회 (전국 CSV 약 64만 행 기반)
  • 3단계 — 계약 직전: 임대인 신원·전입세대 확인 등 체크리스트 가이드 제공
위험 판정 기준
등급전세가율의미
SAFE< 70%정상 범위
CAUTION70 ~ 80%주의 필요
DANGER> 80%위험 — 보증금 회수 어려울 수 있음
UNKNOWN시세 산정 불가수기 확인 필요
연동 공공 API
  • 주소 정규화 — 행안부 juso.go.kr
  • 실거래가 — 국토부 공공데이터포털 (RTMSDataSvc)
  • 건축물대장 — 국토부 건축HUB
  • 등기부등본 — CODEF 샌드박스 (인터넷등기소 대행)
  • 중개사 조회 — 공공데이터포털 CSV (~64만 행)
